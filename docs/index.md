# Credential HUB Public Beta Documentation

Credential HUB is an open-source platform for managing digital credentials,
provider connections, API tokens and encrypted credential storage.

The Consumer interface is a **Beta-1-supported Advanced Integration Flow**.
It requires an administrator to prepare a Credential, Consumer token and
matching grant before Discovery and Resolve can be used.

For support, use the public project community channels listed in the
repository README. Do not publish secrets, tokens or private credential data.
